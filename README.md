# Jagat Kawruh

Landing page (Home) untuk website media pembelajaran, dibuat dengan React + Vite + Tailwind.

## Jalankan lokal

```bash
npm install
npm run dev
```

Build produksi:

```bash
npm run build
npm run preview
```

## Logo

Taruh file logo kamu sebagai:

- `public/logo.png`

Landing page akan otomatis menampilkan logo itu di navbar.
